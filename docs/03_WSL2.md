# 03 — WSL2

## 標準

Ubuntu 24.04 / WSL2 / 通常Linuxユーザー / Bashを初期対象とする。
v0.1のBash bootstrapはUbuntu 24.04以外では停止する。
WSL検出は強制せず、CIやUbuntu検証VMでも実行できる。実行場所はdoctorで確認する。

## 配置

```bash
mkdir -p ~/src ~/worktrees
cd ~/src/agentic-dev-workstation
bash bootstrap/wsl/setup.sh
bash bootstrap/wsl/setup.sh --apply
source ~/.bashrc
```

Linuxから実行するrepositoryは`/mnt/c`へ置かず、`/home/<user>/src`へ置く。
Microsoftの公式案内に基づく方針。Windows Explorerから見るには`explorer.exe .`を使える。
OneDrive同期フォルダにGit worktreeやnode_modulesを置かない。

## PATH

`command -v git`、`command -v python3`、`command -v agy`を確認する。
Linux側でGitやAgentを呼ぶ時は、Windowsの`.exe`が優先されないようにする。
shell設定は`~/.config/agentic-dev-workstation/workstation.bash`へコピーされる。

## systemd / Docker

まず`ps -p 1 -o comm=`でPID 1を確認する。
systemdを必要とするDocker方式を選ぶ場合のみ、Microsoft公式手順で設定する。
既存`/etc/wsl.conf`をテンプレートで丸ごと上書きしない。

## 実機受入

`uname -r`にMicrosoft/WSLの情報があること、`wsl -l -v`でVERSION 2であることを確認する。
doctorのWSL検出だけではWSL2判定にならない。Windows側の一覧と合わせて判断する。
