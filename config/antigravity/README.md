# Antigravity設定方針

認証キャッシュと個人settings.jsonはこのフォルダへ保存しません。
v0.1はAgent固有JSONを配布せず、公式UIで設定します。

導入時に確認する項目:

- WSLのLinuxバイナリを実行していること。
- tmuxで表示を確認し、Inlineを選択すること。
- 利用アカウント、利用枠、課金方式。
- permission/sandboxの範囲。全許可モードを既定にしない。
- ブラウザ・MCPへ与える権限。
- rootのAGENTS.mdを読み、内容を実際に説明できること。

説明と参照先は[Antigravity手順](../../docs/06_ANTIGRAVITY.md)を参照。
